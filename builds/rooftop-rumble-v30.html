v32Added a clearly labeled Delete button directly to each custom-map card; it uses the existing confirmation and safe map-ID deletion flow.
v31Added a quick delete button to every custom-map card. It opens the existing confirmation dialog, so maps can be removed faster without changing the underlying delete behavior.
v29Speed pads now work in both directions with neutral visuals, map-editor objects use their actual in-game models, new themes/backgrounds are available to custom/generated maps, multiplayer hosts can configure more match rules, and hosts can kick players.
v30Gave Desert Sunset, Arctic Sky, and Neon City distinct skies, scenery, atmosphere, and dedicated decoration models; the generator now uses theme-specific scenery instead of the standard rooftop look.
v33Restored the compact × quick-delete control on custom map cards. Clicking it deletes the map immediately without a confirmation dialog.
v27Made background buildings more transparent, removed moving-platform side snap/teleport behavior, and fixed portals to send players to their linked portal with a short cooldown.
v22Shared camera always keeps every active player in frame while biasing the view toward the largest nearby group.
v19 Background pillars remain visually unchanged but no longer have player collision.
v11 Reworked player animations into a detailed slime-style rectangular character: no stick arms or legs, smoother squash/stretch, running bob, jump/fall deformation, slide flattening, wall-slide lean, dash stretch, stun wobble, and tagged reactions.
v12 Fixed the match-intro countdown so the 3–2–1 timer advances correctly in both local and multiplayer play. Fixed multiplayer start/countdown pause desync, removed the circular tagger marker, corrected tag trail layering, and expanded local-play parity for the match intro, roster presentation, tag effects, and match-end statistics.
v25Grey structural support pillars are now walk-through on every map source, including generated maps; only their player collision is removed, while their appearance remains unchanged.
v26Multiplayer startup begins immediately on the host instead of waiting for every guest to finish loading; each guest joins once its own map is ready.
v24Background-layer objects, including background pillars, are now collision-disabled consistently for built-in, generated, and imported maps while remaining fully visible.
v23 Expanded procedural backgrounds for every built-in and generated map, removed the distracting long background line effects, and added cavern-style crystals and glow mushrooms to the generated-map decoration pool.
v18 Removed fixed spawn points and paired teleport exits: match starts, respawns, teleporter pads and the teleport power-up now place players at a random safe spot on top of a floor. Relay still respawns at checkpoints. Also cleanup: removed 18 dead duplicate functions, merged the stacked startMatch/makePlayer overrides into single hook pipelines, guest no longer picks its own respawn spot, custom maps no longer carry spawn pads.
v17 Power-up pickup is now range-only: icons and speech bubbles are render-only and can never block, push, or collide with players. Bubble rendering also uses a compatibility-safe path.
v16 Power-ups are now small readable icons with compact world-space speech bubbles, proximity re-prompts, timed despawns, and stronger pickup hitboxes. Each power-up keeps its distinct effect and visual identity.
v13 Restored local Start Match to the latest feature path so the local countdown, randomized power-ups, roster presentation, tag effects, scoreboard, and match-end statistics all run correctly without using multiplayer networking logic. v15: Fewer, more widely spread power-ups, relocated respawns, slower spawn cadence, and clearer pickup explanations.
v10 Added match intro/end presentation, mode repairs, dynamic tag effects, and expanded multiplayer smoothing/prediction and synchronization.
v9 Added gameplay/power-up parity between local and online play, stronger sliding burst behavior, Survival elimination, Infection setup, and additional power-ups.
v8 Improved randomized power-up spawning, distinct pickup visuals, and repaired Freeze Tag/other new mode initialization.
